# Data sources and redistribution status

| Resource | Role | Included in public package? |
|---|---|---|
| HMDB (https://hmdb.ca/) | Archived disease annotations, exact full InChIKey join in the working project | No |
| Leffingwell-derived odor annotations | Known odor labels in the local atlas | No |
| Pretrained OpenPOM MPNN | Upstream 256D embeddings and 138 predicted descriptors | No weights or training data |
| Local evidence_overlay.json | Frozen coordinates and linked labels | Private companion only |
| Synthetic demo | Test rendering and input schema | Yes |

The OpenPOM revision and checkpoint SHA-256 are now recorded in research/examples/openpom_checkpoint_config.json and the checkpoint forward pass was rechecked. The exact original atlas release, source access dates and redistribution terms remain unaudited. No permission to redistribute third-party records is asserted. Before publishing research data, recover these identifiers and review the source terms. Do not apply a future code LICENSE automatically to database records or model artifacts. A future poster QR link should point to the actual repository after creation; no placeholder repository URL is presented as real.
